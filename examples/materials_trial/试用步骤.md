# RAG Workbench 0.1.12 试用步骤

本包附 `synthetic-ofet.pdf`：两页英文文本型 PDF，专为软件验收编写。
它没有真实论文来源、DOI、作者或实验结果，所有数值均为虚构。

两个入口独立：**“知识库管理 → AI 聊天”用于论文问答**；
**“材料文献”用于提取、审核、结构化存储和跨论文分析**。聊天回答不会自动入库为已批准记录。

## 1. 复测原始薄膜论文的表格（无需 API Key）

原始 `薄膜文献1.pdf` 由发送者另行提供，未放进试用包。

1. 在“知识库管理”导入原始 PDF，确认导入成功，再打开“AI 聊天”。
2. 发送：`请你告诉我PY3-OTS在25、60、100℃下的迁移率分别是多少`。
3. 对照 **PDF 第 3 页 Table 1**（印刷页码 156）：

| 样品 | 沉积基底温度 | 迁移率 cm²/(V·s) |
| --- | --- | --- |
| PY3-OTS | 25 ℃ | 2.3 × 10⁻⁷ |
| PY3-OTS | 60 ℃ | 2.3 × 10⁻³ |
| PY3-OTS | 100 ℃ | 0.01 |

回答须包含三个对应数值、单位和第 3 页来源。可唯一匹配并在原 PDF 本地核对的表格查询
不调用远程模型。若目标不明确，在问题前加 `根据薄膜文献1.pdf 的 Table 1`；
有同名文档时先改成不同名称。无法确认样品、温度或指标时应停止补数，而不是猜测。

## 2. 复测指定论文概况（需自己的 API Key）

按软件根目录试用说明配置 API Key，然后在“AI 聊天”发送：

> 请你阅读这篇薄膜文献1，然后给我论文标题、作者、年份、DOI、材料体系、选择理由，以及对应的结构、薄膜、器件和性能信息

再试：`请你阅读薄膜文献1，告诉我这个论文主要讲了什么`。
逐字段查看引用：标题、作者、年份、DOI 及材料/器件/性能均应有本篇依据；
原文未找到的内容应明确留缺，不凭文件名猜作者或用其他论文补齐。

## 3. 用虚构示例练习审核和存储（无需 API Key）

1. 打开软件，左侧选择“材料文献”，上传本目录 synthetic-ofet.pdf，类型选择正文。
2. 选中文献，预览第 1/2 页并缩放；第 2 页提供器件、工艺与测试条件。
3. 手工新增候选，以第 1 页的 mobility 为例录入下表，添加原文证据与页码。
4. 修改一个字段后移开焦点以触发草稿保存；刷新页面检查是否可以恢复草稿。
5. 核对证据后保存并批准候选，再导出 CSV/ZIP，检查字段与来源关联。

| 字段 | 示例值 |
| --- | --- |
| 材料名称 | TEST-OSC-A（虚构） |
| 样品编号 | SYN-01 |
| 性能 | 场效应迁移率 |
| 原始数值 | 0.42 |
| 原始单位 | cm^2 V^-1 s^-1 |
| 载流子 | hole |
| 工作区间 | saturation |
| 统计口径 | mean of 6 devices |
| 器件 | bottom-gate/top-contact; Si/SiO2/PMMA/TEST-OSC-A/Au |
| 工艺 | spin-coated from 8 mg/mL chlorobenzene; 100 C, 30 min, nitrogen |
| 条件 | nitrogen; 300 K; V_DS = -60 V |
| 方法 | square-root transfer-curve fit in saturation |

第 1 页还含 threshold voltage = -18 V 和 on/off ratio = 3.2 x 10^5，
可以分别创建记录，练习“同一材料、多性能记录、共同条件、不同证据”的关联。
引用第 1 页时请摘录其实际原文，不要把本说明当成论文证据。

有 API Key 时可另外尝试 AI 提取，阅读远程发送范围说明后主动确认。
模型输出是待审核候选；核对原文证据并批准后，才进入默认的已批准数据集。
示例即使被批准也仍是虚构数据，仅在试用工作空间中练习，不作为真实实验或预测训练数据。

## 4. 已批准记录的跨论文分析

1. 在“材料文献”导入不同论文，分别建立并批准要比较的性能记录；跨论文比较至少需要
   两份不同文献。包内只有一份虚构示例，可以先练习单篇记录、图表和导出。
2. 切换“跨论文分析”，按论文、材料、性能指标及实验条件筛选，查看已批准记录数量。
3. 选择比较组或已记录的数值条件为横轴，切换线性/对数纵轴；不同测量口径分组查看，
   “口径待确认”和缺少条件的记录先核对，不直接当作可比实验。
4. 点选散点，或在数值横轴下拖动框选，核对联动记录；选中表格行后查看字段证据和原页。
   点击“清除图中选择”可恢复当前筛选的全部记录。
5. 点击“准备分析导出”，下载分析包中的 CSV；有可绘制数据时下载 SVG/PDF，
   检查导出是否对应当前筛选与选中记录。更改筛选后重新准备导出。

“已批准”是审核状态，“实测/计算/图中读数/引用”是数据来源，二者不能互相替代。
跨论文分析展示已有观测，不会自动提取遗漏字段或预测新材料的性能。
