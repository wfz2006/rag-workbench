# 材料文献首版（本地开发）

本地扩展已提供 PDF/TXT/Markdown 原文导入、实验候选提取、中文表单核对、手工添加、修订历史和 CSV/完整 ZIP 导出。侧栏入口为“材料文献”。当前发布版编号未变，本地改动尚未发布。

## 启动和使用

在项目根目录执行原有 `start.ps1`；或：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.port 8517
```

1. 打开“材料文献”，导入一篇带文本层的 PDF。TXT/Markdown 也可使用。正文先导入，补充材料选择所属正文。
2. “原文证据”页可以查看解析块和 PDF 页序。文本路径不解析图像、扫描文字或保留表格单元格坐标。
3. 有 API Key 时选择 OFET/OPV/通用方向，查看完整处理范围及预计批次，主动勾选发送文字的确认后提取。正文提取包含关联 SI；单独选 SI 时只处理该文件。此操作会调用当前模型，可能产生费用。
4. 候选在中文表单中核对。填写材料、性能、原始数值、单位、样品；工艺、测试条件和结构按原文摘录。完整 JSON 编辑放在高级区域。
5. 每个非空业务字段批准前均需 evidence 证据。到“原文证据”复制模板，field 选择字段，quote 保留原文。可用同一 quote 支持多个字段；来源范围、引文和完整数值会被检查。字段内容首版要求原文摘录，暂不支持把翻译/改写当作原始字段。
6. 勾选逐项核对确认后批准。保存候选、批准和拒绝均产生修订；过时版本不能覆盖新版本。无 Key 时同样可以手工添加、审核和下载。
7. 在“导出”点击“准备导出文件”，下载 CSV 或完整数据包。默认仅包含已批准记录；改变筛选或修订后需重新准备。

## 存储和导出

材料模块位于当前工作区 `data_dir/materials/`：独立 `materials.sqlite3`、`originals/` 和任务锁。旧的问答数据库和 FAISS 索引格式保持原样。

CSV 为 UTF-8 BOM，一行一项观测。`dataset.json` 是完整包的权威表示，材料、样品、器件、工艺、条件嵌入每条观测；包内包含文档、原文块、字段证据、修订历史、原始文件和 SHA-256 清单。当前没有一键回导功能；本轮验证了引用闭包及 JSON/CSV 同一版本一致性，不宣称已完成导入回读。

明确区分数值原文与规范值：只对小范围、大小写敏感的单位白名单及明确数值换算。范围、误差或未知单位的规范值留空，原文始终保留。导出中的引用与历史版本采用同一捕获版本范围，原件缺失或损坏时完整导出会明确失败；重传原件可恢复。

## 解析器和当前边界

- 默认解析使用项目已有 pypdf，不新增模型下载。扫描 PDF 明确提示需要 OCR。
- 已编写可选 Docling 适配器，保存文本、表格、可用页内坐标和完整文档 JSON。当前环境未安装 Docling，真实 Docling/OCR 运行未验收。适配器要求 Docling 在运行进程环境中可导入；本轮未实现独立 worker 部署，不应直接按“独立环境安装后即可使用”理解。
- 当前没有更改 pyproject/uv.lock，也没有升级主环境。准备引入 Docling 时先在副本中做依赖/模型/实际 PDF 验证，再锁定依赖。
- 文本抽取使用现有 ChatProvider，输出经过领域和证据校验。LangExtract、RDKit、Pint 和曲线工具尚未集成；不是本轮已完成能力。
- 提取逐批覆盖所有解析文本，每批最多接受 30 项候选；任务完成表示批次处理完成，不代表已召回所有实验事实。需检查漏提、多样品混淆和方法口径。
- 提取同步执行、逐批保存进度及错误。失败可查看已存候选并重试；重跑同内容候选不覆盖人工审核。暂不提供进程退出后的自动续跑、跨批次自动关系补全。
- 分子图片识别、曲线数字化、独立训练与性能预测未实施；文字结构字段不等同于识别了分子图或绘制了器件模型。
- 尚无用户真实论文。本轮以合成两页 PDF 和模拟模型验证功能与界面，没有调用真实付费模型，也不报告科学抽取准确率。

接下来用真实论文及 SI 检查字段和样品关系，收敛首批器件与 2–3 个指标，再决定是否推进 OCR、复杂表格或结构识别。
