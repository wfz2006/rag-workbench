# 材料文献首版（本地开发）

材料扩展已提供 PDF/TXT/Markdown 原文导入、实验候选提取、原页对照、中文字段核对、持久草稿、手工添加、修订历史和 CSV/完整 ZIP 导出。侧栏入口为“材料文献”。本次代码同步至 GitCode `main`，版本号和既有 Release 未更改。

## 启动和使用

在项目根目录执行原有 `start.ps1`；或：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.port 8517
```

PDF 页图使用可选 `preview` 依赖。本轮已在当前开发环境安装并锁定 `pypdfium2`；其他环境可执行 `uv sync --extra preview`。缺少组件时仍可核对解析文字和下载原件，不影响记录编辑。该组件只在本地渲染页面，不调用 OCR 或远程模型。

1. 打开“材料文献”，导入一篇带文本层的 PDF。TXT/Markdown 也可使用。正文先导入，补充材料选择所属正文。
2. “原文证据”页可以查看解析块和 PDF 页序。文本路径不解析图像、扫描文字或保留表格单元格坐标。
3. 有 API Key 时选择 OFET/OPV/通用方向，查看完整处理范围及预计批次，主动勾选发送文字的确认后提取。正文提取包含关联 SI；单独选 SI 时只处理该文件。此操作会调用当前模型，可能产生费用。
4. 宽屏在“提取与核对”中并排查看原页和记录；窄屏可切换“编辑记录 / 原文预览”。字段证据的“在原文中查看”会切到对应正文或 SI 页；相同引文支持多个字段时合并展示。PDF 支持跳页和缩放；没有可靠坐标时只显示原页、引文，不伪造精确框。可按状态筛选或进入下一条待审核记录。
5. 填写材料、性能、数值、单位、样品；工艺和条件按原文摘录。字段失焦后保存到独立本地草稿，页面会说明成功或失败。刷新/重开后在“恢复本地草稿”中预览并主动恢复；旧基础修订只可查看和手工合并。草稿不会自动批准或改写实验记录；点击保存、批准或拒绝才会提交正式记录。可用“放弃此草稿”还原。尚未离开输入框的字符不保证已经写盘。
6. 每个非空业务字段批准前均需 evidence 证据。展开“关联原文证据”，选择原文块、支持的字段和原文引文，点击“关联到字段证据”，无需手写 JSON。同一引文可支持多个字段，重复关联会去重，也可多选移除。来源范围、引文和完整数值仍由服务检查；完整 JSON 编辑保留在高级区域。字段内容首版要求原文摘录，暂不支持把翻译/改写当作原始字段。
7. 勾选逐项核对确认后批准。保存候选、批准和拒绝均产生修订；过时版本不能覆盖新版本。无 Key 时同样可以手工添加、审核和下载。
8. 在“导出”查看实际导出条数，点击“准备导出文件”，下载 CSV 或完整数据包。默认仅包含已批准记录；改变筛选或修订后需重新准备。完整包因原件问题生成失败时不会保留旧 ZIP，CSV 仍可下载。手工新增保存成功后会清空新增区并选中新记录，避免再次点击产生重复。

模型发送确认绑定当前论文、关联补充材料、指标模板及实际模型接口配置；范围变化后需重新勾选。审核确认也会在字段修改后清除。并发修订时旧版本草稿不会自动覆盖新记录，可展开旧草稿手工合并。

## 存储和导出

材料模块位于当前工作区 `data_dir/materials/`：正式记录在 `materials.sqlite3`、原件在 `originals/`，编辑草稿在独立的 `drafts.sqlite3`（草稿 schema 2）。草稿不进入 CSV/完整数据包，也不能替代正式记录备份。旧的问答数据库和 FAISS 索引格式保持原样。

多窗口编辑的草稿更新和删除均检查版本，删除重建不会复用旧版本。发生冲突时保留当前输入，可在恢复区对照磁盘草稿；不静默覆盖其他窗口。正式记录保存成功但草稿清理失败时，会明确提示“记录已保存，草稿未清理”，保留磁盘草稿供核对。

CSV 为 UTF-8 BOM，一行一项观测。`dataset.json` 是完整包的权威表示，材料、样品、器件、工艺、条件嵌入每条观测；包内包含文档、原文块、字段证据、修订历史、原始文件和 SHA-256 清单。当前没有一键回导功能；本轮验证了引用闭包及 JSON/CSV 同一版本一致性，不宣称已完成导入回读。

普通导出 `measurements.csv` 的 `value_normalized` 和 `unit_normalized` 只填写可换算的单值，保留大小写敏感的单位核对。范围、带误差的值或单位无法识别时，两列留空，原文保存在 `value_raw` 和 `unit_raw`。已批准记录可从「跨论文分析」下载分析包，`observations.csv` 中的 `analysis_kind` 区分单值、范围、带误差和界限，并以独立列提供可核对的上下限和误差。导出中的引用与历史版本采用同一捕获版本范围，原件缺失或损坏时完整导出会明确失败；重传原件可恢复。

## 跨论文分析

在“提取与核对”的“实验字段与观测来源”补充退火、成膜、器件几何和测量条件，关联相应字段证据后批准。打开“跨论文分析”，按论文、材料、指标或实验条件筛选。OFET 的迁移率、开关比和阈值电压可按比较口径绘制单条观测，也可用有明确单位的实验条件作散点图横轴。比较条件缺失时仍可看原始观测和证据。

点击图点或选择表格行可查看对应字段和 PDF 页。表格保留未绘制记录，包括单位不明确、只给界限或不适用于当前坐标轴的结果。准备分析导出后可下载记录、证据页码、筛选参数、图表数据及 SVG/PDF。图表使用 Altair，静态图由本地依赖生成。

试点的原文、样品归属和复核步骤见 [OFET 真实论文试点](MATERIALS_OFET_PILOT.md)。表头缩放因子和 PDF 上下标须在原页核对，含糊的指数保持原文。

单独使用 `scripts/build_structured_markdown.py` 清洗 PDF 时，可用 `--provenance paper.provenance.json` 导出原 PDF 的 SHA-256 以及 Markdown 块对应的原页和文本层行号。

## 解析器和当前边界

- 默认解析使用项目已有 pypdf，不新增模型下载。扫描 PDF 明确提示需要 OCR。
- 已编写可选 Docling 适配器，保存文本、表格、可用页内坐标和完整文档 JSON。当前环境未安装 Docling，真实 Docling/OCR 运行未验收。适配器要求 Docling 在运行进程环境中可导入；本轮未实现独立 worker 部署，不应直接按“独立环境安装后即可使用”理解。
- `pyproject/uv.lock` 仅新增 PDF 页图的 `preview` 可选依赖。本轮没有安装 Docling 或升级其他主依赖；准备引入 Docling 时先在副本中做依赖/模型/实际 PDF 验证，再锁定依赖。
- 文本抽取使用现有 ChatProvider，输出经过领域和证据校验。LangExtract、RDKit、Pint 和曲线工具尚未集成；不是本轮已完成能力。
- 提取逐批覆盖所有解析文本，每批最多接受 30 项候选。证据齐全的候选可保存待核对，核心字段缺少证据的候选计入任务记录中的「未通过校验」。无法核对的辅助字段留空。任务完成表示批次处理完成，仍需检查漏提、多样品混淆和方法口径。
- 提取同步执行、逐批保存进度及错误。失败可查看已存候选并重试；重跑同内容候选不覆盖人工审核。暂不提供进程退出后的自动续跑、跨批次自动关系补全。
- 分子图片识别、曲线数字化、独立训练与性能预测未实施；文字结构字段不等同于识别了分子图或绘制了器件模型。
- 尚无用户真实论文。本轮以合成两页 PDF 和模拟模型验证功能与界面，没有调用真实付费模型，也不报告科学抽取准确率。

接下来用真实论文及 SI 检查字段和样品关系，收敛首批器件与 2–3 个指标，再决定是否推进 OCR、复杂表格或结构识别。
