# 0.1.6：第六轮审查修复记录

备份：`artifacts/review-round6-before.zip`。保留 `.env`、正式知识包/索引/数据库、模型与所有旧发行包。测试均在独立目录，未调用付费 API。

## 逐项处理

| 问题 | 处理与实际边界 |
| --- | --- |
| 编辑粘滞 | 输入区显示正在修改哪个失败问题、发送的替换语义与取消按钮。取消、清空草稿、切换页面/会话会清除目标。已提交的编辑仍按原位替换处理；没有把所有新问题静默当作替换。 |
| 时间线瞬移/重复 | RunningTurn 与带替换 ID 的 UnsavedTurn 在原消息对的位置显示，生成前后位置一致。保存失败只显示新结果的临时覆盖；数据库旧失败内容保留，手动移除覆盖后恢复旧记录，不显示两份相同回合。 |
| Markdown | 逐 claim 检测未闭合的反引号/波浪号围栏并在展示、复制边界补齐，防止吞噬下一 claim。行内来源需顶层 paragraph_open 的 map 覆盖源码末行且末行不是反斜杠；链接定义、结构块使用独立行。原始答案不改写。报告建议的 paragraph_close.map 通常为空，未直接照搬。 |
| 实际索引状态 | 配置持久化后通过缓存的新服务检查活动索引，连续保存 Top-K/调试项仍保留不兼容警告与重建入口。恢复默认值若重新匹配活动签名则不误报。移除无写入方的旧 toast 消费分支。知识库删除/重建错误就地显示；0 失败文档只提示全部就绪。 |
| 词法候选 | 原始片段位置替换，最长不重叠键优先，轮询分配单键提案与多键组合预算，避免改写新插入的别名及第一键耗尽名额。relations 加入“原人物 + 关联目标”提案。追问提取保守词法焦点，例如“王伦 死”“林冲”，不将代词/口语首尾双字混入覆盖率分母。 |
| 标题 | Repository 提供手动命名标志及第一条 assistant ID；首轮重试用新问题的临时标题，明确手动命名为“新会话”也不被覆盖。只有移除第一回合才尝试自动重命名。 |
| 窄窗滚动 | 跳转按钮绝对定位在输入区上方，透明容器不占盒模型高度；固定锚点留白。浏览器检查显隐前后高度/顶部变化小于 1px，跳转后最新消息底部与目标锚点误差小于 3px。顶栏使用短渐隐边缘。 |

没有采用“只匹配 related 目标就通过覆盖率”的宽松方案：关联配置是检索提示，不能代替资料里的实体关系和证据。纯目标命中仍可作为 BM25 候选显示，只有满足向量/词法/受控邻接门槛后才进入证据判断；没有绕过 LLM 证据验证。此处是对审查建议的保守取舍，不能宣称已经解决任意关系检索。

1. 编辑提示、取消、切页与清空草稿后，新问题追加且不覆盖旧记录；正常编辑提交仍原位更新。
2. 中间回合生成、保存失败覆盖及手动移除，位置与消息对数量保持稳定。
3. 未闭合代码、尾部反斜杠、引用链接定义、下一段正文、系统剪贴板。
4. 分块改变后第二次保存即时项仍需重建，恢复默认值不误报，缺原件重建错误保留页面，成功时文案无歧义。

## 兼容与限制

- 不改变索引签名；0.1.1–0.1.5 索引无需仅因升级重建。检索规则变化没有据此编造真实知识包召回率/准确率，未执行付费评测。
- 围栏补齐只发生在展示/复制结果，不修复任意错误 Markdown、语言语法或模型事实；数据库原文保持不变。
- 未保存覆盖仍为浏览器临时状态，硬刷新/关闭会丢失；数据库里的旧失败记录保留。移除覆盖不等于保存。
- 词法焦点是保守语法规则，复杂主语、嵌套指代、多个关系目标仍可能召回不足；原实体约束和最多 40 个覆盖率提案保留。多于可用配额的键无法保证全部展开。
- 原位修改旧问题不改写之后的成功回合，重试上下文仍只取目标之前的历史。
- 未做干净 Windows 虚拟机、所有 DPI/显卡或真实付费 API 验收；便携包未签名。
