# 材料文献交互改进验收（2026-11-02）

起点为本地 `ea9812f`。本轮仅本地开发，不提交、推送或更改封存版本；不更改正式数据、密钥配置或依赖环境。

## 已完成

- 编辑字段从浏览器 form 缓冲改为独立会话草稿。切原文、记录、文献、全局页面后可恢复；明确保存才写入数据库，支持显式放弃。当前论文和记录也会恢复。
- 记录已被其他操作修订时，旧草稿单独保留并提示，不自动覆盖新版本。
- 手工新增保存成功后清空新增区、切到全部记录并选中新候选；失败保留输入，防止重复点击新增相同旧值。
- 原文证据可以通过选择原文块、字段和引文直接关联；去重和多选移除，保留高级 JSON 编辑。
- 文献、SI 集合、指标模板或实际模型接口配置变化后撤销旧发送授权；字段修改后重新核对批准。
- 编辑折叠区使用稳定标识并跟踪展开状态，避免输入触发刷新后意外收起。已存在记录时默认收起模型提取区，便于核对。
- 导出显示实际条数；重新准备失败撤下旧 ZIP；完整包失败时保留 CSV，并持续说明原因。
- 会话管理名称与后台自动标题同步，保留用户尚未提交的命名草稿。
