# RAG Workbench 0.1.12 · Windows x64 一键试用版

1. 将整个 ZIP 解压到可写目录，例如 D:\Apps\RAG-Workbench。不要在压缩软件里直接运行。
2. 双击 RAG Workbench.exe。无需安装 Python、运行命令或管理员权限。
3. 按下面两个入口选择试用内容；软件不会自动导入论文或示例。

请保留 EXE 同目录的 runtime、resources、models 文件夹。首次启动会准备独立的
user-data 工作空间并复制约 92 MiB 的公开检索模型，请稍等。关闭窗口会结束本窗口的本地服务。

## 两个入口

| 要做的事 | 入口 | 数据来源 |
| --- | --- | --- |
| 问指定论文的内容、作者或表格数值 | “知识库管理”导入 PDF → “AI 聊天”提问 | 导入的原 PDF 与引用页 |
| 提取、审核性能记录，再作跨论文比较 | “材料文献”导入 → “提取与核对” → “跨论文分析” | 人工核对后批准的材料记录 |

两处导入独立。聊天回答不会自动变成材料数据库中的已批准记录。

## 原始薄膜论文复测

原始 `薄膜文献1.pdf` 由发送者另行提供，不包含在试用 ZIP 中。

1. 在“知识库管理”导入该 PDF，等待导入成功，再进入“AI 聊天”。
2. 发送：`请你告诉我PY3-OTS在25、60、100℃下的迁移率分别是多少`。
3. 应依次得到 **2.3 × 10⁻⁷、2.3 × 10⁻³、0.01 cm²/(V·s)**；
   引用应指向 **PDF 第 3 页 Table 1**（印刷页码 156）。温度指沉积时的基底温度。
4. 展开引用并对照原表的样品、温度、指标和单位。若存在多份相关文档，在问题中
   明确加上 `根据薄膜文献1.pdf 的 Table 1`；同名文档先改成可区分的名称。

可唯一匹配并在本地核对的这类表格查询无需 API Key。匹配不明确或没有找到对应单元格时，
应报告信息不足，不应补造数值。本例用于复测指定表格，不代表任意扫描件或图表都可自动读出。

## 指定论文概况复测

配置自己的 API Key 后，在“AI 聊天”发送：

> 请你阅读这篇薄膜文献1，然后给我论文标题、作者、年份、DOI、材料体系、选择理由，以及对应的结构、薄膜、器件和性能信息

也可问：`请你阅读薄膜文献1，告诉我这个论文主要讲了什么`。
逐项核对回答中的原文引用；标题、作者、年份和 DOI 应来自论文证据，缺失字段应说明未找到。
材料、结构、工艺、器件和性能须保留对应关系，不能把另一篇论文的信息填进来。

## 无 Key 可以试什么

- 导入 PDF/TXT/Markdown 文献、标记正文与补充材料。
- 本地 PDF 翻页、缩放，核对材料、器件、工艺、测试条件与原文证据。
- 手工新增候选、编辑、保存/恢复草稿、批准记录并导出 CSV/ZIP。
- 在“知识库管理”导入资料，离线执行本地语义/关键词检索。
- 上述可唯一匹配的本地表格查询，以及已批准记录的筛选、绘图与分析导出。

“材料文献”和“知识库管理”各有独立的导入入口，请按用途选择。示例 PDF 是虚构的
有机半导体 OFET 数据，只用于演示界面与数据关联，不能当作真实论文或实验结论。
试用步骤与示例数值见“试用示例/试用步骤.md”。应用不会自动导入示例。

## AI 提取与其他聊天回答

需要网络、自备 API Key 与服务余额。软件不内置 Key，也不承诺免费远程推理。
在窗口顶部“工作空间 → 配置 API Key”打开本试用版独立的 user-data/.env，填写：

DEEPSEEK_API_KEY=你的Key

保存后可刷新应用或重开窗口。不要编辑开发项目的 .env。默认使用配置中的 DeepSeek 接口；
如需兼容接口，可配置 RAG_LLM_BASE_URL 与 RAG_LLM_MODEL，再重开窗口。

材料页的 AI 提取会先说明发送的文本范围，并要求主动确认远程发送。
聊天中的检索片段也可能发送给配置的远程模型。保密论文应按所在机构要求使用；
本地预览、手工录入和离线检索不需要调用远程模型。

## 跨论文分析

在“材料文献”逐篇导入，手工录入或用 AI 生成候选，核对原文、样品、数值、单位、
工艺和测试条件后批准。自动提取成功不等于实测数据已核实；计算、图中读数与转引数据
也应按实际来源标注。已批准表示完成审核，不会把虚构示例变成真实实验结果。

进入“跨论文分析”，按论文、材料、性能指标与实验条件筛选，选择比较组或有数值的条件作横轴，
切换线性/对数刻度。点选散点，或在数值横轴下框选，检查联动记录及字段证据；
不同测量口径或缺少条件的记录应分开判断。点击“准备分析导出”，下载包含 CSV 的分析包，
有可绘制数据时还可下载 SVG/PDF。改变筛选或图中选择后重新准备导出。

先用 `试用示例/synthetic-ofet.pdf` 练习录入、批准和图表操作。它只是一份虚构示例；
跨论文比较需另备至少两份不同文献及对应的已批准记录。详细步骤见同目录“试用步骤.md”。

## 数据、备份与升级

所有首次使用产生的内容都在软件目录的 user-data 中：

- .env：本试用版的 API 配置。
- knowledge：资料、会话、检索索引，以及材料记录、证据与独立草稿库。
- models：公开检索模型的工作副本。
- browser：本地 WebView2 状态。
- .streamlit/config.toml：本工作空间的主题等配置。
- desktop.log：本地服务诊断日志，分享前请检查私人内容。

关闭软件后备份整个 user-data 即可。升级请解压到新目录，再复制工作空间备份，
不要覆盖正在运行的旧目录。转发给其他人时只发送原始 ZIP，避免把使用后的
user-data、API Key、论文或数据库重新打包给别人。

## 系统要求与功能范围

支持 Windows 10/11 x64，需要 .NET Framework 4.6.2+ 和 Microsoft Edge WebView2 Runtime。
缺少 WebView2 时可在微软官方页面安装：
https://developer.microsoft.com/microsoft-edge/webview2/

本包未进行代码签名。若系统显示未知发布者，可核对随 ZIP 提供的 SHA-256 与来源。
本机已安装 WebView2 的 Windows 环境验收，不代表已经覆盖所有干净系统、DPI 或显卡组合。

当前支持文本型 PDF、指定论文问答、可核对的定点表格查询、手工/AI 候选、
证据核对、草稿恢复、跨论文筛选绘图和导出。
扫描件 OCR、图表曲线自动取点、分子结构图片识别及材料性能预测尚未实现。
PDF 只有真实坐标证据才显示定位框，不会凭空生成高亮。

程序只监听本机 127.0.0.1。首次运行若失败，请先完整解压到可写目录并检查 WebView2；
诊断在 user-data/desktop.log。本包附公开 BGE 模型，无需首次联网下载模型。

第三方许可证保留在 resources/licenses、runtime 的各依赖目录中；
BUILD_INFO.json 记录基线版本，SHA256SUMS.json 记录包内逐文件校验值。
